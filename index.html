Pearson

Sinal = direção. |r| = força. 0–0,2 muito fraca; 0,2–0,4 fraca; 0,4–0,6 moderada; 0,6–0,8 forte; 0,8–1 muito forte.

VI × VD

VI = fator que influencia/causa. VD = efeito ou resultado medido.

Problema → Pergunta → Objetivo

Problema = evidência/lacuna. Pergunta = investigação. Objetivo = verbo no infinitivo.

Escalas

Nominal = nome; Ordinal = ordem; Intervalar = intervalos sem zero absoluto; Razão = zero absoluto.

Abordagens

Dedutiva: geral→particular. Indutiva: particular→geral. Hipotético-dedutiva: problema→hipótese→teste. Dialética: tese→antítese→síntese.

Tipos

Exploratória = descobrir. Descritiva = descrever/medir. Explicativa = explicar relações/causas.
